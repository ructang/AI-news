### [OpenRouter 加入 Stripe，据报道收购超 70 亿美元](https://openrouter.ai/blog/announcements/openrouter-is-joining-stripe/) ⭐️ 8.0/10

OpenRouter 宣布加入 Stripe，此前有报道称 Stripe 将以超过 70 亿美元收购这一广受欢迎的 AI 模型路由 API 平台。OpenRouter 让开发者通过单一 API 访问多家模型供应商，并自动选择价格或性能更优的提供商。对 AI 应用开发者来说，这意味着模型聚合与支付基础设施可能进一步整合，降低对接和计费复杂度；同时 Stripe 可借助 OpenRouter 进入 AI 模型分发环节。关键事实包括：OpenRouter 是一家主流 AI 模型聚合平台，收购金额被报道为 70 亿美元以上，官方公告确认加入 Stripe。

hackernews · rvz · 8月19日 17:32 · [社区讨论](https://news.ycombinator.com/item?id=49364559)

**「背景」：** OpenRouter 是一个聚合多家 AI 模型提供商的 API 网关，开发者可以用同一接口调用不同模型，并让供应商在价格和质量上竞争。Stripe 是以支付与计费基础设施为核心的科技公司，据 Bloomberg 报道，双方已敲定超过 70 亿美元的收购协议，OpenRouter 将并入 Stripe 的 AI 基础设施版图。对应用开发者而言，这意味着模型路由服务可能与支付、计量和账务系统更深度整合，AI 应用调用模型时的成本归属与计费流程或许会变得更像标准支付基础设施。

**「社区讨论」：** 社区既有认可也有担忧。有长期用户认为 OpenRouter 的价值在于让模型供应商围绕统一 API 竞争，避免锁定；也有评论指出默认路由常选最便宜而非最高性能，建议设置性能下限。还有人希望看到类似开放银行那样的去中介化协议，而非由 Stripe 这类中间商继续主导；另有观点认为 Stripe 可以顺水推舟，把 AI 模型的计量、记账与支付能力整合进产品。
