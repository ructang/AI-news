### [Qwen3.8-Flash-Next open-source model with hybrid N-gram embeddings](https://qwen.ai/blog?id=qwen3.8-flash-next) ⭐️ 8.0/10

Qwen released Qwen3.8-Flash-Next, an open-weights multimodal MoE model that pairs a 125B-parameter main model with 51B N-gram embeddings and activates 6B parameters per token. The architecture introduces a hybrid N-gram embedding design, drawing attention from builders for its compute/memory tradeoff and cost-per-token profile. Early community reports highlight strong coding performance and low API cost, with one user citing about $0.45 for a session involving heavy cached input. Others question how the roughly 176B-parameter footprint will quantize and whether it will run on typical 128GB unified-memory machines. The release matters because Qwen continues to push open-source efficiency, making it relevant for entrepreneurs weighing self-hosted versus API-based model options.

hackernews · tosh · Aug 26, 12:52 · [Discussion](https://news.ycombinator.com/item?id=49448210)

**「Background」:** Qwen3.8-Flash-Next is the latest open-weights model from Alibaba&\#x27;s Qwen team, following earlier Flash-series releases designed for efficient deployment across serving frameworks. It is a multimodal mixture-of-experts model that upgrades attention, residual, embedding, and optimization; its main 125B-parameter model is supplemented by 51B N-gram embeddings, with only 6B parameters active per token. This hybrid n-gram approach is a technique that has also appeared in DeepSeek research and in a lightweight form in Google&\#x27;s Gemma models, aiming to improve model capacity without proportional inference cost. The weights and configuration files are available through Hugging Face, ModelScope, and the Qwen blog, with support for vLLM, SGLang, TokenSpeed, and similar serving stacks.

**「Community Discussion」:** Commenters are generally impressed by coding and reasoning results, with one noting Qwen3.8-Flash-Next beat Qwen3.8-27B cleanly and another reporting productive use on complex merges and regression bisection for under $0.50. Skepticism centers on the effective model size: the 125B main model plus 51B N-gram embeddings makes quantization and local inference uncertain, and one user doubts it will fit in a 128GB unified-memory setup. Several also asked for intuition behind N-gram embeddings, indicating the architecture remains unfamiliar to many practitioners.
