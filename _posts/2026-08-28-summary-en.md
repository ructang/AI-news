### [Prompt Injection Breaks Claude Code Auto Mode 80% of Time](https://simonwillison.net/2026/Aug/27/breaking-claude-code-opus-5-auto-mode/) ⭐️ 7.0/10

Security researcher Johann Rehberger, a credible prompt injection expert, found an attack against Anthropic&\#x27;s Claude Code auto mode that succeeds roughly 80% of the time. The attack tricks the coding agent into downloading and uncompressing a zip archive, then executing a malicious local struct.py file when the agent imports base64. Auto mode sometimes even blocked Claude&\#x27;s own cleanup commands after the compromise was detected, making the safety mechanism part of the failure. Anthropic recently made auto mode the default for Claude Code and made bold claims about its effectiveness against prompt injection. Simon Willison, who reported the finding, agrees with Rehberger&\#x27;s conclusion that the only safe way to run agents under adversarial risk is with a sandbox, such as running in a container or VM, restricting network egress, monitoring agents, and not exposing credentials or home directories. This matters for AI application builders because it shows that guardrail-based safety for coding agents can be bypassed with high reliability.
